# K Kiran Kumar — Anti-Gravity Cinematic Portfolio

## Run
1. Extract `Kiran_AntiGravity_Portfolio.zip`.
2. Open the extracted folder and double-click `index.html`.
3. For editing, open the folder in Antigravity or VS Code.

## Files
- `index.html` — page structure and content
- `style.css` — cinematic design and responsive layout
- `script.js` — Three.js star field, scroll reveals, and interactive hover tilt
- `kiran-photo.jpeg` — portrait used in the hero section
- `portfolio-concept.png` — generated design reference

## Customize
Edit project descriptions and skills to match your actual experience. Project links currently point to your GitHub profile; replace them with individual repository links when available. Three.js, GSAP, and fonts load from CDNs, so internet access is required for those enhancements. Basic page content and CSS still work without them.

## Publish
Upload the contents of this folder to a GitHub repository, then enable GitHub Pages in the repository settings.
